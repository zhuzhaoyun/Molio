## AI 搜索应用增强信息

> 用于联想应用商店 AI 搜索场景。字段限约 194 字（超限会被截断），以下均已控制在限内并保证句子完整。

### 核心功能（165 字）

```
1. 多格式入库：笔记、整本书、带图 PDF、Word/PPT/Excel 转 Markdown 知识库，自动生成知识图谱与双向链接；
2. AI 研究写作：接入 Claude Code、Codex 等引擎，基于全库资料问答、研究、写作，产出自动写回；
3. AI 出题练习：生成题卡，作答后 AI 按参考答案逐点评分并回写题卡
```

### 差异优势（188 字）

```
架构不同：不是“笔记软件加一个 AI 按钮”，而是让 AI 引擎直接以你的知识库为工作目录，读写真实文件；
引擎中立：可接 Claude Code、Codex 等外部引擎，用自有密钥，不锁定单一模型；
零迁移成本：资料是纯 Markdown 文件，可直接打开已有的 Obsidian 库，也能随时带走；
本地优先：数据不出本机，离线可用，AI 产出自动回写入库，积累越用越厚。
```

> 两栏分工：核心功能写「能做什么」，差异优势写「凭什么选它」，不重复列举功能。

### 更新内容（v0.4.3）

```
1. 出题练习升级：新增填空题型与主观题作答，AI 逐点评分并回写题卡，题干选项支持 Markdown 与图片；
2. 技能导入更顺手：导入前可预览内容，桌面端支持拖拽导入；
3. 问答更贴库：问答规则按各知识库自动生成；
4. 阅读与图谱优化：正文与题干图片改为真实地址加载，知识图谱导出不再裁切图例；
5. 稳定性提升：新增空闲看门狗与分层超时提示，修复流式回答中断、文件树刷新异常等问题。
```

### 使用攻略（196 字）

```
1. 建库：首次启动自动创建知识库，也可指定已有文件夹，支持直接打开 Obsidian 目录；
2. 导入：拖入笔记、电子书、PDF、Office 文档，或用 Chrome 扩展一键剪藏网页；
3. 接入 AI：在设置中填入 Claude Code / Codex 等引擎的 API 密钥；
4. 使用：对话提问、写作、出题，结果自动存回知识库；需要发布时打开排版编辑器，一键分发到多个平台。
```
