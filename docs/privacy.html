Molio Connect 隐私权政策

生效日期：2026年7月7日  |  最近更新：2026年7月7日

核心承诺：Molio Connect 不会向任何远程服务器发送用户数据。所有剪藏内容、高亮标注、配置信息都仅保存在您的本地设备（本机浏览器 + 本机桌面应用），由您完全掌控。

1. 概述

Molio Connect 是一款浏览器扩展，用于将网页内容剪藏、高亮标注后保存到您本机运行的 Molio 桌面应用（一个本地知识库管理程序）中，作为您的个人知识库文档。

本隐私权政策详细说明本扩展如何收集、使用、处理和分享用户数据，涵盖扩展本身及其配套的本机桌面应用通信链路。

2. 我们收集的数据

本扩展仅在以下场景、出于以下目的读取或产生数据：

2.1 您主动剪藏的网页内容

  • 触发条件：仅当您通过点击扩展图标、使用键盘快捷键、右键菜单、或打开侧边栏主动发起剪藏操作时，才会读取当前标签页的页面内容。
  • 读取范围：当前活动标签页的正文、标题、URL、以及您选择的高亮片段。
  • 不剪藏时不读取：在未触发剪藏操作的普通浏览过程中，扩展不会读取、记录或监听您访问的任何网页内容。

2.2 高亮标注数据

您在网页上创建的文本高亮、批注，会由扩展读取并与该页面 URL 关联保存。

2.3 用户配置

您在扩展选项页面设置的本地 Molio 服务端地址（默认为 http://localhost:3100）及其他偏好设置。

2.4 不收集的数据

  • 不收集浏览历史、cookies、表单填写内容、密码
  • 不收集您的 IP 地址、设备指纹、地理位置
  • 不收集个人身份信息（姓名、邮箱、电话等）
  • 不收集任何遥测、崩溃日志、使用统计

3. Chrome 权限及其数据用途

下表列出扩展申请的每项 Chrome 权限及其对应的数据操作，便于您了解每个权限的必要性：

权限 用途 涉及数据
activeTab 仅在用户触发剪藏时访问当前标签页 当前页面正文、标题、URL
clipboardWrite 将剪藏结果复制到系统剪贴板 剪藏后的文本
commands 支持键盘快捷键（Ctrl+Shift+O 等）触发剪藏 / 高亮 / 阅读模式 不涉及数据，仅响应按键
contextMenus 右键菜单一键剪藏 不涉及数据，仅注册菜单项
sidePanel 打开侧边栏显示剪藏 / 高亮操作界面 不涉及数据，仅 UI 载体
storage 保存用户配置（本地服务器地址等）和高亮数据 配置项、高亮元数据
scripting 向当前页面注入脚本，用于提取正文、渲染高亮 当前页面 DOM 片段
declarativeNetRequest 处理扩展与本机 Molio 桌面应用通信时的跨域请求 仅本机回环请求（localhost）
<all_urls> (host_permissions) 允许您在任意网页上触发剪藏与高亮 您主动触发剪藏时的当前页面

4. 数据如何使用

收集到的数据仅用于以下单一用途——将网页内容保存为您本机的知识库文档：

  1. 剪藏：提取当前网页正文 / 标题 / URL，传输到本机 Molio 桌面应用。
  2. 高亮标注：保存您在网页上做的文本高亮，并与该 URL 关联。
  3. 配置存储：记住您设置的本地 Molio 服务地址，用于后续通信。

5. 数据如何存储

  • 配置项：使用 Chrome Storage API 保存在浏览器本地，不离开您的设备。
  • 高亮数据：使用 Chrome Storage API 保存在浏览器本地，按 URL 索引。
  • 剪藏的网页文档：通过 HTTP 请求发送并保存在您本机运行的 Molio 桌面应用（默认地址 http://localhost:3100），存储于您本机文件系统。Molio 桌面应用不连接任何远程服务器。

6. 数据如何分享

不向任何第三方分享用户数据。

具体而言：

  • 剪藏内容、高亮数据仅发送给您本机的 Molio 桌面应用（localhost 回环网络请求），不经过互联网。
  • 配置数据仅保存在本机浏览器 storage 中，不发送到任何外部服务。
  • 我们不出售、不出租、不共享任何用户数据给任何第三方公司、组织或个人。
  • 我们不使用任何第三方分析、广告、追踪服务。
  • 我们不收集、不传输任何遥测或崩溃上报数据。

7. 数据保留与删除

  • 浏览器端：您可在扩展选项页面手动清除所有本地存储的配置和高亮数据；或卸载扩展时，浏览器会自动清除该扩展的所有 storage 数据。
  • Molio 桌面端：剪藏的文档保存在您本机文件系统，由您自行管理。您可以在 Molio 应用内随时删除任意文档，卸载应用后数据不会保留。
  • 无云端：由于本扩展不使用任何云端服务，因此不存在云端数据保留期限的问题。

8. 儿童隐私

Molio Connect 不面向 13 岁以下儿童设计，不会故意收集儿童个人信息。由于所有数据仅保存在用户本机、不上云，儿童隐私风险被降到最小。

9. 本政策的变更

如本隐私权政策有重大变更，我们将通过以下方式通知您：

  • 更新本页面顶部的"最近更新"日期；
  • 在扩展下次更新时通过 Chrome Web Store 更新说明进行提示；
  • 必要时在扩展内弹出显著通知。
