Molio Connect 隐私权政策

生效日期：2026年6月10日

核心原则：您的数据完全由您掌控。所有数据存储在本地，不会上传到任何第三方服务器。

1. 我们收集的数据

本扩展程序仅在本地收集以下数据：

  • 网页剪藏内容：您主动选择的网页正文、标题、URL
  • 用户配置：本地 Molio 服务端地址等设置项
  • 对话历史：您在侧边栏中与 AI 的问答记录

2. 数据存储位置

所有数据均存储在您的本地浏览器中（通过 Chrome Storage API）。我们不会将数据上传到任何远程服务器。

3. 数据传输

剪藏内容仅传输到您自己运行的本地 Molio 桌面应用（默认地址：http://localhost:3100）。您完全控制自己的数据，可随时删除。

4. 数据共享

我们不会将用户数据出售、共享或提供给任何第三方。

5. 您的权利

您可以随时：

  • 在扩展设置中清除所有剪藏数据和配置
  • 卸载扩展以彻底删除所有本地存储的数据
  • 导出或备份您的数据

6. 联系我们

如有隐私问题，请通过 GitHub Issues 联系我们：https://github.com/zhuzhaoyun/Molio/issues
