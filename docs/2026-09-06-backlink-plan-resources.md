# Molio 资源库外链方案（目标：卖动 /resources.html 的知识图谱资源）

> 日期：2026-09-06　｜　承接 `docs/2026-09-03-seo-strategy-resources.md`（该文档 P0 已落地，外链原为 P2 且仅一句话）
> 核心结论：**外链要分「传权重」和「卖货」两套打，中文环境下这两者几乎不重合。** 你卖的是三类完全不同人群的东西（文史古籍 / 医学 / AI 工程），一条通用外链策略必然低效——按 SKU 分人群投放才是这份方案的重点。

---

## 一、先修三个漏权重的洞（不修，外链做一半白做）

### 1.1 🔴 `www.molio.cn` 与 `molio.cn` 未 301 归一 —— 已产生实际权重分散

`apps/landing-page/molio.conf:9` 的 443 server 块里 `server_name molio.cn www.molio.cn;`，两个主机名同时直出相同内容，没有跳转；`:4` 的 80→443 用的是 `https://$host$request_uri`，`$host` 会把 www 原样带进 HTTPS，等于全链路保留双主机。

**这不是理论风险，已被搜索引擎当成两个站分别收录了。** 本次检索的公开结果里同时出现：

- `https://molio.cn/` — 标题「Molio 墨流— 让 AI 拥有你的个人知识底座」
- `https://www.molio.cn/` — 标题「Molio 墨流 — 别再和每一个 AI 从零开始｜会成长的 AI 知识空间」

同一首页，两套标题描述、两条索引记录。外链分别打向两个主机时，权重被劈成两份，谁也不够强。

**改法**：443 块拆成两个 server，`www.molio.cn` 单独 `return 301 https://molio.cn$request_uri;`（写死目标主机名，不要用 `$host`）。改完用 `curl -I https://www.molio.cn/resources.html` 确认返回 301 且 Location 无 www。

### 1.2 🟠 详情页 URL 不可读，社交传播与外链锚文本都吃亏

商品详情页是 `/resource/01M10RZP9118BA6YRBZ1D4FKM2.html` 这种 ULID。好处是永久稳定、不会因改名失效——**适合做外链落地页**；坏处是发在小红书/知乎/微信群里像一串乱码，点击率和可信度都低，用户也没法口口相传。

**改法**：加语义别名路由，如 `/resource/zizhitongjian-tupu.html` → 内部映射到 ULID，同时详情页 canonical 仍指 ULID（避免自造重复内容）。

注意 `molio.conf:38` 的正则是 `^/resource/[0-9A-Za-z]+\.html$`，**不含连字符**，带 `-` 的 slug 会掉进 `location /` 被 `index.html` 兜住（变成软 404）。加 slug 必须同时把正则放宽为 `[0-9A-Za-z-]+`。这是最容易踩的一步。

### 1.3 🟠 百度站长 / Google Search Console 未验证 —— 外链的放大器缺失

外链的本质是「告诉搜索引擎这里有内容值得抓」。但你没接主动推送，百度只能靠爬虫自己顺着链接摸过来——新站、新 URL、还是商业页，百度抓取偏保守，等的时间以周计。

**顺序很重要：先验证 + 提交 sitemap + 接主动推送，再开始发外链。** 反过来做，外链发出去的那几天正是收录窗口，白白错过。

落地：`ziyuan.baidu.com` 站点验证（加 `baidu-site-verification` meta 或上传校验文件到 landing-page 根目录）→ 提交 `sitemap.xml` → 接普通收录主动推送 API，把 3 个免费款详情页 URL 和 `/resources.html` 先推一遍。GSC 同理，DNS 验证最省事。

## 二、一个决策：外链别都打 `/resources.html`

`resources.html` 是列表页，外链全指向它会有两个问题：权重摊薄到 11 个商品上、单个商品词排名起不来；而且列表页承载的是「知识图谱资源」这种泛词，跟你真正能成交的长尾词（「红楼梦人物关系图」「妇产超声 胎儿畸形 鉴别」）不匹配。

**分工：**

| 落地页 | 外链用途 | 理由 |
|---|---|---|
| `/resources.html` | 品牌类、工具类、开源类外链 | 承接「Molio 有什么」的泛需求，列表页 SSR 已能露出全部商品 |
| `/resource/{id}.html` 具体商品 | 垂直内容外链、社群分享 | 有 Product JSON-LD 可出富摘要（价格直接显示在搜索结果），转化路径最短 |
| `/blog/*.html` | 长尾信息词外链 | 用信息词引流量，文内再内链到商品页——比直接发商品链接更容易被平台接受、被读者点开 |
| GitHub 仓库 | 开发者/AI 工程人群 | 你最高权重的自有资产 |

**免费款（《金瓶梅》图谱、《周易》六十四卦、老庄思想图谱）是外链武器，不是成本。** 免费资源在知乎、豆瓣、小红书、各类论坛里可以直接给链接而不像广告，平台不删、读者愿点；进来之后详情页底部已有「相关资源」6 条互链，天然把流量导向 ¥5.9–¥49.9 的付费款。外链优先推免费款落地，再用站内内链完成转化——这条链路你已经建好了，缺的只是外部入口。

## 三、四层外链渠道（按投入产出排序）

### 第 1 层：自有高权重资产 —— GitHub（零成本，先做）

仓库 `github.com/zhuzhaoyun/Molio` 已开源。GitHub 域名权重极高，README 上的链接是你能拿到的最硬的外链，而且完全自主可控。

- README（中英双份，`README.md` + `README_zh.md`）新增一节「现成知识底座」，列出 3 个免费资源 + 资源库入口，锚文本用具体资源名而非「点击这里」
- README 顶部徽章区下方加一行资源库链接
- 若有 GitHub Pages 或 Releases 页面，同步加上

这类站本身权重高、且被百度/Google 频繁抓取，提交通过后是长期存量外链。**逐个提交前先看站点当前是否开放投稿/收录，规则会变，别照抄清单盲投。**

### 第 3 层：内容型外链 —— 已验证有效，继续放量

**这条路你已经跑通了。** 检索结果里能看到你自己的两篇博客园文章被正常收录：`cnblogs.com/yaolin1228/p/20405889`（Molio 开源）和 `cnblogs.com/yaolin1228/p/20782508`（Obsidian + Claude Code + 微信AI 缝进一个软件）。说明内容型外链对你这个站是可行的，不用从零试错。

放量方向：

- **一文多投**：现有 6 篇博客（Obsidian 替代、Claude Code GUI、本地知识库、Web Clipper、微信排版、Molio vs Obsidian）同步到 CSDN、掘金、知乎专栏、简书、51CTO、InfoQ 写作平台。每篇文末统一加资源库链接。注意各平台对导流链接的容忍度不同，知乎专栏可放、部分平台需放在评论区或个人简介
- **博客园/CSDN 的百度权重最好**，优先级最高
- **每周一篇蓝海词新文**（延续原 SEO 文档 P2 结论），选题直接绑商品：写「《资治通鉴》怎么读才不白读」时自然带出资治通鉴图谱；写「AI 为什么读不懂中医古籍」时带出中医经典知识库

## 四、锚文本规范

外链失败最常见的原因是锚文本乱来。三条规则：

1. **多样化，别堆同一个词**。全部外链都用「知识图谱下载」会像买卖链接。理想分布：品牌词（Molio、墨流）约 30%、商品名（《资治通鉴》知识图谱）约 40%、自然语句（这里有个整理好的）约 20%、裸 URL 约 10%
2. **品牌词与商品词分开打**。品牌词外链指向 `/` 或 `/resources.html`，商品词外链直指对应详情页
3. **禁止做的事**：批量买链接、群发软件、垃圾目录站批量提交、互链群。百度对链接买卖的识别很成熟，一旦被判定，商品页是商业属性最强的页面，最先受影响。这类操作短期看收录涨，长期把域名信誉做坏，得不偿失

## 六、效果判断口径

延续原 SEO 文档结论：**外链是复利，不要以天为单位判断。**

- 2–4 周：看到收录变化（百度收录数、GSC 索引覆盖上升）
- 4–8 周：看到外链带来的直接流量（GA4 里 referral 维度能拆出具体来源站）
- 8–12 周：看到目标词排名变化（「红楼梦人物关系图谱」「资治通鉴知识图谱」「妇产超声 知识图谱」）
- 转化侧单独看：详情页流量 → 微信支付成功率，目标 > 3%（原 SEO 文档已定此口径）

**关键区分**：第 3 层（内容型）和第 2 层（收录站）看排名和自然流量；第 4 层（转化型）只看直接出单数，别看它排名贡献——它本来就不传权重。混着看会误判渠道价值，把能出单的小红书砍掉。
