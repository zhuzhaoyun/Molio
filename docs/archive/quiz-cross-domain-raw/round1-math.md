【大题作答·第3题】
题干：某公司销售一种商品，每件售价 20 元时每天可售出 100 件；售价每上涨 1 元，每天少售出 2 件。每件商品的成本为 12 元。设售价上涨 x 元（x 为非负整数）。
(1) 写出每天的销售额 W（元）关于 x 的函数解析式，并说明 x 的实际取值范围；
(2) 若每天的销售额不低于 2300 元，求售价上涨 x 元的整数值范围，并写出相应的售价范围；
(3) 求每天利润的最大值，以及取得最大利润时售价应上涨多少元（此时售价为多少元）。
评分点：
1. 写出销售额解析式 W(x) = (20 + x)(100 - 2x) = -2x² + 60x + 2000，并指出 x 的实际范围由销量非负与售价非负决定，即 0 ≤ x ≤ 50 且 x 为非负整数
2. 把销售额条件化为一元二次不等式：-2x² + 60x + 2000 ≥ 2300，整理得 x² - 30x + 150 ≤ 0
3. 求出方程 x² - 30x + 150 = 0 的两根 x₁ = 15 - 5√3，x₂ = 15 + 5√3，得不等式解集为 {x | 15 - 5√3 ≤ x ≤ 15 + 5√3}
4. 结合 x 为非负整数取整，得 x = 7, 8, …, 23，即售价上涨 7 元到 23 元
5. 写出对应的售价范围：27 元 ≤ 售价 ≤ 43 元
6. 写出利润解析式 P(x) = (20 + x - 12)(100 - 2x) = -2x² + 84x + 800
7. 指出利润是开口向下的二次函数，最大值在顶点处取得，对称轴 x = -84/(2×(-2)) = 21，最大利润为 1682 元
8. 答出取得最大利润时售价上涨 21 元，此时售价为 41 元，销量为 58 件
出处：wiki/concepts/一元二次不等式.md；wiki/concepts/一元二次不等式的解法.md；wiki/concepts/函数的最大值与最小值.md
题目指纹：5521c6f8

答：（1）W=-2x^2+60x+2000, 0≦x≦50;
(2)9≦x≦23,售价范围[54,82];
(3)2450元，上涨15元，售价35元

解析：
【批改·第3题】得分 2/8
1. 命中｜(1) 写出 W(x) = (20+x)(100-2x) = -2x²+60x+2000，且范围 0 ≤ x ≤ 50，与评分点完全一致。
2. 部分｜(2) 是拿 (1) 中正确的 W(x) 去列 W(x) ≥ 2300 的，但未写出等价不等式 -2x²+60x+2000 ≥ 2300 整理得到的 x²-30x+150 ≤ 0，且最终给出的范围有误。
3. 未中｜全程没有解方程 x²-30x+150 = 0 得出两根 x₁ = 15-5√3、x₂ = 15+5√3，也没有写出解集 15-5√3 ≤ x ≤ 15+5√3。
4. 部分｜(2) 给出了整数区间且上界 23 正确，但下界写成 9，正确应为 7，即 x = 7, 8, …, 23。
5. 未中｜售价范围写成 [54, 82]，正确应为 27 ≤ 售价 ≤ 43；且与自己给的 x = 9~23 也不自洽（20+9 = 29，20+23 = 43）。
6. 未中｜(3) 没有列出利润解析式 P(x) = (20+x-12)(100-2x) = -2x²+84x+800；给出的 2450 元其实是 x = 15 时的销售额 W(15) = 35×70，把销售额当成了利润。
7. 未中｜利润是开口向下的二次函数，最大值应在顶点处取得，对称轴 x = -84/(2×(-2)) = 21，最大利润为 1682 元；作答中的 x = 15 是销售额 W 的对称轴，不是利润 P 的。
8. 未中｜应上涨 21 元、此时售价 41 元、销量 58 件；作答给的是上涨 15 元、售价 35 元。

**错因讲解**

第一问完全正确：每天销量为 100-2x 件，售价 20+x 元，两者相乘得销售额解析式；x 的上界由销量非负（100-2x ≥ 0）决定为 50，下界由售价上涨幅度与售价非负决定为 0。（出处：[[一元二次不等式的解法]]）

第二问丢了根的计算。销售额不低于 2300 即 -2x²+60x+2000 ≥ 2300，两边同乘 -1整理得 x²-30x+150 ≤ 0；用求根公式，Δ = 900-600 = 300 > 0，x₁ = (30-10√3)/2 = 15-5√3 ≈ 6.34，x₂ = 15+5√3 ≈ 23.66。因为二次项系数为正，解集取两根之间，即15-5√3 ≤ x ≤ 15+5√3。x 为非负整数，还要「把数学解集与实际范围取交集」做取整还原，得 x = 7, 8, …, 23，售价 20+x 即 27 元到 43 元。（出处：[[一元二次不等式的解法]]，其中例4「摩托车产量与创收」是同一类「解不等式后取整还原」的范例）

第三问的关键是把「销售额」与「利润」分开。利润 P(x) = (8+x)(100-2x) = -2x²+84x+800，开口向下，顶点横坐标 x = 21，代入得最大利润 P(21) = 29×58 = 1682 元，即售价上涨 21 元、售价 41 元、每天卖 58 件。（出处：[[函数的最大值与最小值]]，实际问题的最高、最大类目标翻译成二次函数后，最值就在顶点处）学生答案里的 2450 元恰好是 x = 15 时 W 的最大值——那是「卖得最多钱」而不是「赚得最多钱」，成本12 元没有进入计算，这是本题最大的概念性错误。
