## 1. 为什么需要这次验收

#381 的批改是 **LLM 概率行为**：协议写得再死，模型不照做就只有降级路径兜底。而 #381 交付后**从未做过跨域验收**——2026-10-27 那次真机只跑到一半就撞出「小数得分 `1.5/5` 导致整块批改被丢弃」的 bug（修复见 `e2b3d2a1`，随 #381 合入 main）。

所以本次验收要回答的问题不是「能不能用」，而是**「批改 + 回写在不同知识形态下稳不稳、准不准」**。

## 2. 验收方法

三轮，各用一个真库、一条自然语言指令、一道大题（外加客观题），验七项判据。每轮**故意写错**（漏步骤 / 错史实 / 错前提）以观察批改是否抓得住。

### 判据表

| # | 检查项 | 通过 | 不通过 = bug |
|---|---|---|---|
| ① | 出题 | 题卡渲染，题型随指令 | 只有文字讲解、无题卡 |
| ② | 作答物化 | 消息含 `【大题作答·第N题】` + 题干 + 评分点 + 出处 + 题目指纹 | 缺物化 |
| ③ | 批改格式 | 回复以 `【批改·第N题】得分 X/Y` 开头 | 自由格式（**降级，不算 bug**，但要记降级率） |
| ④ | 回写 | 题卡行头出现得分徽标 X/Y，可展开逐点评定 | 徽标缺失或逐点为空 |
| ⑤ | **一致性** | **X/Y == 逐点加权总和**（命中 1 / 部分 0.5 / 未中 0） | 对不上 |
| ⑥ | 准确性 | 批改指出的错误**确实是作答里那个错** | 张冠李戴、编造没写的错误 |
| ⑦ | 重答覆盖 | 同题重答 → 新批改覆盖旧分数 | 两个徽标并存 |

③ 不通过不算 bug——skill 遵从是概率性的，模型不按格式回就是降级路径，聊天里照样有批改。

## 4. 两个已知缺口

### 4.1 第 2 轮未验证回写链路

第 2 轮的作答消息**缺 `【大题作答·第N题】` 标记行与 `题目指纹` 行**（第 1、3 轮都有）——是手工贴录而非走「作答」按钮发送。回写靠「指纹:题号」配对，无指纹即无法配对。

**影响**：回写链路的跨域覆盖是 **2/3**（数理 + 法律），人文域未覆盖。
**不补跑的理由**：小数分回写已由单测 + E2E 双重覆盖（`apps/web/test/quizAnswer.test.ts:150`、`apps/web/e2e/quiz.spec.ts:1136`，均用 `1.5/5` 场景），真机重跑属重复劳动。

### 4.2 评分点之外的错误抓不到（协议的结构性特征）

第 2 轮作答开头写「商鞅变法（**秦始皇**时期）」——商鞅是**秦孝公**时期的人，这是硬伤。已核实**库内无此错误**（`资治通鉴` 库中「秦始皇」仅出现在曹叡、蒙恬等无关条目），系模型自编，而 8 个评分点无一覆盖「变法时期」，**批改自然无从发现**。

**根因**：skill 1.5.0 批改协议明写「批改标准就是消息里列出的评分点，不要自己另立标准或加码」。这句本身是对的（防模型加码乱判），但副作用是**评分点构成封闭判定域**——未覆盖的维度天然漏检。

**注意**：这不是「批改质量不够」，是「判据边界」的性质。协议中第 2、4、5 条（讲错因、引出处、拿不准就说拿不准）本就是开放式的，模型有能力在讲解里发现史实错误——第 3 轮就自发补了「立论与归结的补足」（超出全部 7 个评分点）。

**当前决定：暂不改 skill。** 等下一轮真机若再冒出同类「评分点外的明显事实错误未被抓」，再一次性把规则写细——现在用一个案例定规则可能过窄。（观察项已记入 [2026-11-03-quiz-trace-visibility-design.md](../2026-11-03-quiz-trace-visibility-design.md)）

## 5. 结项口径（重要）

本次验收证明的是：

> ✅ **「批改 + 回写」在数理 / 人文 / 法律三种知识形态下行为稳定**——格式合规、得分自洽、出处可溯。

本次验收**没有**证明的是：

> ❌ **「批改质量在所有域都够好」**——第 4.2 节的史实漏抓说明质量仍有提升空间。

两者要分开说。「跨 3 域验收完成」= 行为稳定，不 = 质量完美。

### 附录 A · 第 1 轮 · 数理（高中数学）

**题**（二次函数应用题，3 小问：写解析式 / 解不等式求整数范围 / 求最大利润）

**作答**（故意漏步骤，把销售额当利润）：

```
答：（1）W=-2x^2+60x+2000, 0≦x≦50;
(2)9≦x≦23,售价范围[54,82];
(3)2450元，上涨15元，售价35元
```

**批改**：

```
【批改·第3题】得分 2/8
1. 命中｜(1) 写出 W(x) = (20+x)(100-2x) = -2x²+60x+2000，且范围 0 ≤ x ≤ 50，与评分点完全一致。
2. 部分｜(2) 是拿 (1) 中正确的 W(x) 去列 W(x) ≥ 2300 的，但未写出等价不等式 -2x²+60x+2000 ≥ 2300 整理得到的 x²-30x+150 ≤ 0，且最终给出的范围有误。
3. 未中｜全程没有解方程 x²-30x+150 = 0 得出两根 x₁ = 15-5√3、x₂ = 15+5√3，也没有写出解集 15-5√3 ≤ x ≤ 15+5√3。
4. 部分｜(2) 给出了整数区间且上界 23 正确，但下界写成 9，正确应为 7，即 x = 7, 8, …, 23。
5. 未中｜售价范围写成 [54, 82]，正确应为 27 ≤ 售价 ≤ 43；且与自己给的 x = 9~23 也不自洽（20+9 = 29，20+23 = 43）。
6. 未中｜(3) 没有列出利润解析式 P(x) = (20+x-12)(100-2x) = -2x²+84x+800；给出的 2450 元其实是 x = 15 时的销售额 W(15) = 35×70，把销售额当成了利润。
7. 未中｜利润是开口向下的二次函数，最大值应在顶点处取得，对称轴 x = -84/(2×(-2)) = 21，最大利润为 1682 元；作答中的 x = 15 是销售额 W 的对称轴，不是利润 P 的。
8. 未中｜应上涨 21 元、此时售价 41 元、销量 58 件；作答给的是上涨 15 元、售价 35 元。
```

**错因讲解**（节选）：

> 第三问的关键是把「销售额」与「利润」分开。利润 P(x) = (8+x)(100-2x) = -2x²+84x+800，开口向下，顶点横坐标 x = 21，代入得最大利润 P(21) = 29×58 = 1682 元，即售价上涨 21 元、售价 41 元、每天卖 58 件。（出处：[[函数的最大值与最小值]]）学生答案里的 2450 元恰好是 x = 15 时 W 的最大值——那是「卖得最多钱」而不是「赚得最多钱」，成本 12 元没有进入计算，这是本题最大的概念性错误。

【批改·第1题】得分 4.5/8
1. 部分｜商鞅变法的"破坏世袭、全力耕战、法令公布于众"方向对，但缺什伍连坐、告奸与斩敌首同赏、按军功授爵的具体法令，更未引"道不拾遗、山无盗贼，民勇于公战、怯于私斗"这十年实效原文。

**错因讲解**（节选，最见功力的一段——抓出关键误读）：

> 最要紧的一处是第 7 点评分点上的一处曲解。司马光原文明写"商君尤称刻薄，又处战攻之世，天下趋于诈力，犹且不敢忘信以畜其民，况为四海治平之政者哉"——这是**赞**商鞅处在人人诈力的时代仍不敢忘信，是把徙木立信当作正面典型，用来反衬"为四海治平之政者"更应如此。作答把徙木之信判为"小信""权宜之信"，与原文的褒扬方向正好相反……
>

### 附录 C · 第 3 轮 · 法律（fakao-xingfa）

**题**（2023 法考刑法主观题：挂失补办与柜台取款的定性，3 种观点 + 2 种定性 + 表态 + 法律关系）

**作答**：四问完整作答。

**批改**：

```
【批改·第1题】得分 6/7
1. 命中｜写明陈某通过挂失排除迟某对存款债权的占有、取得资金支配，属转移占有型财产犯罪，成立盗窃罪。
2. 命中｜指出虚构卡丢失、隐瞒银行卡已出卖与资金归迟某支配的事实，使银行陷入错误认识，被骗人为银行、被害人为迟某，构成三角诈骗。
3. 部分｜侵占罪的结构（变占有为所有）正确，但前提写反了：陈某已把卡出卖给迟某，名义持卡人是迟某而非陈某，不能说「存款债权归账户名义人陈某占有」，否则侵占说无法成立。
4. 命中｜认为取款只是既遂后变现、未侵犯新法益，属不可罚的事后行为。
5. 命中｜指出取款时隐瞒无实质取款权限、欺骗银行工作人员，银行基于错误认识交付现金，该环节符合诈骗罪构成要件。
6. 部分｜只支持了挂失定盗窃（与解析立场一致），但对取款表态为不可罚的事后行为，解析立场是取款定诈骗罪；且在挂失部分主张三角诈骗、在取款部分又以银行仅是结算机构无财产损失否定诈骗，前后论证互相抵消。
7. 命中｜明确指出二者是同一法益侵害流程中的接续行为，不分别定罪、不数罪并罚，只以一罪论处，与解析立场「两行为只侵犯一个法益、择一重罪论处」一致。
```

**错因与补充**（节选）：

> 2. **表态部分的自相矛盾需要收敛**。你在挂失环节靠「银行陷入错误认识」立起了诈骗说，又在取款环节以「银行仅是结算机构、无财产损失」否定了诈骗。两个环节的事实是连续的……所以更稳妥的表态是：挂失定盗窃，取款定诈骗，两行为就同一笔存款债权与银行现金只侵犯一个法益，择一重罪论处。

> 3. **答案的整体骨架是对的**：先定占有归属，再选罪名，再单独评价取款，最后用法益同一性收尾，这正是库内归纳的答题顺序（[[存款占有的归属]]「答题骨架」条）。
