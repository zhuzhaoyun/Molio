========================================
  Molio macOS 安装说明 — 请先阅读
========================================

如果你双击 Molio.app 后出现以下提示：

    "Molio.app" 已损坏，无法打开。
    你应该将它移到废纸篓。

这是 macOS Gatekeeper 的正常行为，应用本身没有任何问题。
Molio 是安全的开源软件，不包含恶意代码。

========================================
  解决方法（任选一种即可）
========================================

方法一（推荐，最简单）：
  在 Finder 中，对着 Molio.app 点击右键（或按住 Control 点击）
  → 在菜单中选择 "打开"
  → 在弹出的对话框中点击 "打开" 按钮。
  之后就可以正常双击打开了。

方法二（终端命令，一劳永逸）：
  1. 将 Molio.app 拖入 /Applications 文件夹
  2. 打开终端（在 Launchpad 中搜索 "终端"）
  3. 粘贴以下命令并回车：
     sudo xattr -d com.apple.quarantine /Applications/Molio.app
  4. 输入你的 Mac 登录密码（输入时不显示），回车

========================================
  为什么会有这个提示？
========================================

macOS 要求从互联网下载的应用必须经过 Apple 公证
（Notarization），这需要 Apple Developer Program 会员
（年费 $99）。Molio 目前未加入该计划，因此会触发
Gatekeeper 的安全警告。应用本身完全安全。

项目地址：https://github.com/zhuzhaoyun/Molio

> 提示：如果你已经安装了 Molio 但忘记了这份说明，
> 可以在 Finder 中右键点击 Molio.app → "显示包内容"，
> 在 Contents 文件夹中找到 `使用前必读.txt`。
