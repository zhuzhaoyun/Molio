# 向知识库提问

问答有两种范围，按钮位置不同：

- **问一篇文档**：打开文件后，点内容区上方的「💬 问答」。问题会带上这篇文档作为上下文。
- **问整个知识库**：文件面板上方标签栏最左侧有常驻的「💬 问答」按钮；没有打开文件时，主内容区也会给出「与知识库问答」的入口。

## 悬浮还是停靠

对话面板默认浮在右下角，可以拖动位置、拉宽拉高，也可以在面板头部切换成停靠侧边栏。知识库页切到停靠时，文档区会自动让出宽度，两边对照着看。

## 提问小技巧

- 说清你要的产物：「把这三篇笔记的差异整理成表格」比「帮我看看」有用。
- 用 `@` 引用库里的另一篇文档，用 `/` 调用技能。
- 回答里的引用可以点开原文；长回答可以一键「保存到知识库」，变成新文档。

> 对话在后台继续跑，切到别的页面不会中断；运行中的状态在会话标签上有标记。
