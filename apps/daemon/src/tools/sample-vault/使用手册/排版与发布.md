# 排版与发布

写好的文章可以直接在 Molio 里排版，再发到公众号等平台。

## 排版

1. 打开一篇 Markdown 文档。
2. 点右上角「排版」进入左右分栏：左边写，右边实时预览。
3. 点「样式」调整主题、字体、字号、主题色。
4. 用「复制」拿到带样式的富文本，粘贴到公众号编辑器；或点「发布」走多平台发布。

## 发布前

- 代码块、表格、公式、图片在预览里过一遍。
- 「复制」会连同当前主题 CSS 一起带走，粘贴后样式不会丢。
- 发布到外部平台需要在「渠道」里先完成对应平台的授权。

> 排版只改变呈现，不改原文；随时可以「退出排版」回到阅读模式。
