# 读书笔记 · 如何阅读一本书

莫提默·艾德勒把阅读分成四个层次，层层包含：

1. **基础阅读**：认字、读懂句子。
2. **检视阅读**：规定时间内抓出这本书在谈什么——先看目录、序言、结尾，再快速通读。
3. **分析阅读**：把一本书嚼碎。核心是四个问题：这本书在谈什么？作者细部说了什么、怎么说的？说得有道理吗？这本书跟我有什么关系？
4. **主题阅读**：围绕一个问题读多本书，让作者们互相对话。

## 我的用法

- 拿到新书先做检视阅读，判断值不值得进入分析阅读。
- 分析阅读时把每个章节的主张写成一句话，最后拼回全书骨架。
- 主题阅读只围绕一个具体问题选书，不按「书单」读。

## 和知识库的关系

检视阅读像「浏览文件树」，分析阅读像「精读一篇并做笔记」，主题阅读像「用问答把多篇笔记连起来」。这也是我把它放进示例库的原因：工具的使用方式和阅读方法可以互相印证。
