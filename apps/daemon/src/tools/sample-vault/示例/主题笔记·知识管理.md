# 主题笔记 · 知识管理

知识管理不是「收藏更多」，而是让积累在需要时能被调用。三个环节：

- **捕获**：随手记、剪藏、导入。捕获时不做整理，降低摩擦。
- **组织**：给笔记加标题、标签和链接。链接比文件夹更重要，因为一个问题往往横跨多个目录。
- **调用**：写作、决策、问答时能找回来。找不回的知识等于没有。

## 常见误区

1. **只进不出**：工具里堆了几千条，但从不回看。解法是给「调用」设计场景，例如固定每周写一篇复盘。
2. **过度分类**：目录越分越细，最后自己都找不到。解法是少建目录、多建双链。
3. **追求完美笔记**：一条笔记改十遍，不如先写下粗糙版本，用到时再迭代。

## 一个最小闭环

捕获 → 每周挑一条重写 → 写作时引用 → 把成品存回库。循环一次，知识就从「存过」变成了「用过」。
