# 关键词机会调研（GEO 数据）

> 记录目标关键词、搜索意图、竞争度。用于指导内容方向与商品命名。
> 调研时间：2026-08。数据来源：搜索引擎结果页观察 + 竞品分析。

## 一、蓝海词（竞争低、意图明确、直接对应商品）

### 1. 红楼梦人物关系图谱
- **搜索意图**：用户想找一张现成的红楼梦人物关系图 / 图谱，用于阅读、研究、教学。
- **竞争现状**：现有结果多是 2014 年前后的旧图、学术数据集，或零散的图片。
- **Molio 优势**：唯一「结构化 + 可导入 AI 知识库」的付费商品，可直接用于图谱问答。
- **打法**：商品页标题直接命中「红楼梦人物关系图谱」，FAQ 覆盖「怎么用、能查什么关系、怎么导入」。

### 2. 妇产超声知识体系
- **搜索意图**：超声科医生 / 规培生想找系统化的妇产超声知识结构。
- **竞争现状**：几乎无结构化付费产品，多是教科书目录、零散文章。
- **Molio 优势**：¥39.9 商品，目标用户（超声科医生）付费意愿强、搜索意图极明确。
- **打法**：这是最被低估的蓝海词，值得单独做落地页 + 医学场景 FAQ。

### 3. 资治通鉴知识体系 / 资治通鉴 知识图谱
- **搜索意图**：历史爱好者、研究者想找资治通鉴的结构化知识。
- **竞争现状**：中低，有相关书籍但无「可导入 AI 工具的结构化图谱」。
