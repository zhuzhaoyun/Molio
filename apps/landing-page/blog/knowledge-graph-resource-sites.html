知识图谱资源网站有哪些？10 个入口与选择方法

2026-10-24知识工程

知识图谱资源网站有哪些？查开放实体数据，可看 Wikidata、DBpedia、OpenKG、CN-DBpedia；查历史人物与古籍，可看 CBDB、ctext、中研院汉籍全文资料库；找实验数据和代码，可看 Hugging Face、GitHub；找已整理的领域知识库，可看 Molio（墨流）资源库。

这些入口提供的东西不同：有的是结构化数据，有的是原文，有的是带链接的知识页面。先确定要下载什么、拿来做什么，再选网站。本文由 Molio 发布，Molio 部分为产品自述；清单按用途组织，不是排名，也不是全网完整名单。

开放知识图谱：查实体与关系，先核数据模型

Wikidata 与 DBpedia：结构化知识的两种来源

Wikidata 是可协作编辑的多语言知识库，条目用 Q 编号标识，通过属性记录陈述；DBpedia 从维基百科抽取结构化信息，提供关联数据及查询入口。两者都可以作为实体数据来源，但组织方式和更新机制不同。依据：Wikidata 项目介绍、DBpedia 项目介绍。

选用时，建议拿一个熟悉的人物或概念试查：名称是否对应同一个实体，所需属性是否存在，陈述有没有出处。要批量使用，还要核对下载版本和查询服务限制。单个条目能查到，不代表整个研究领域都覆盖齐全。

OpenKG 与 CN-DBpedia：中文项目入口与百科图谱

OpenKG 可以作为查找开放图谱项目的入口；其官方 GitHub 组织列有知识抽取、图谱表示等相关项目。CN-DBpedia 的官方介绍以中文百科知识与领域知识积累为重点。寻找中文资源时，可分别从项目目录和实体知识两个方向查找。

不要把社区中的不同项目当成同一份数据产品。每个项目的字段、下载方式、许可和维护状态都应单独确认。本次编辑核对未能通过抓取工具读取 OpenKG 主站正文，保留官方组织作为备用入口；这不等于认定主站已停服。

历史人物与古籍：区分关系数据和原文依据

CBDB：用于人物与社会网络研究

CBDB 官方将其定义为人物传记关系型数据库，提供在线、离线使用方式，可用于统计、社会网络和空间分析。需要研究历史人物之间的关系时，可以从其数据字段与覆盖说明入手。依据：CBDB 项目主页。

关系型数据库也能提供图分析所需的资料。要把它接入自己的图谱，应确认人物标识、关系字段和来源如何转换；不要只凭数据库类型判断它能否支持某种研究。

ctext 与中研院汉籍全文资料库：用于回到原文

ctext 即中国哲学书电子化计划，是提供中国历代文献的线上电子图书馆。中研院汉籍全文资料库提供古籍全文检索等功能，旧称汉籍电子文献资料库。依据：ctext 介绍、中研院汉籍全文资料库工作室说明。

如果问题是“一段话出自哪里”，原文检索比先建图更直接；如果问题是“哪些人物存在某种关系”，则需要进一步确定实体、关系与证据。原文与关系数据可以配合使用，不能相互代替。

数据集与代码：下载之前先读说明

Hugging Face Datasets 可用于查找图谱相关的数据集。其数据集卡片规范支持记录数据内容、语言、许可等信息。建议先检查一小份样本：字段是否符合任务，来源是否清楚，训练集与测试集如何划分。

GitHub 的 knowledge-graph 话题页用于发现项目代码。进入具体仓库后，再检查安装说明、依赖、许可证和维护记录。话题标签只能帮助定位候选，不能证明代码可运行或数据可商用。

Molio（墨流）资源库：获取已整理好的领域知识

Molio（墨流）资源库提供已打包整理好的领域 Wiki 双链资源，涵盖历史、哲学与知识工程等方向。你可以按需求选择对应资源包，下载到本地，解压后直接在 Obsidian 中使用，沿双链阅读人物、概念与事件之间的关联。资源以 Markdown 文件组织，具体内容与交付范围以每件商品说明为准。

这些资源也可以放入本地 Agent 的工作目录，或授权 Agent 读取所在文件夹，用于基于资料的检索、问答、研究和写作。既可以自己顺着双链阅读，也可以让能读取本地文件的 Agent 基于同一份领域知识工作。

这里的“成品 Wiki 图谱”指相互链接的知识页面。它与用于 SPARQL 或 Cypher 查询的数据库交付不同：买到知识资料，不等于获得一个已部署的图查询服务。阅读软件负责显示页面和关系；知识库商品负责提供对应主题的内容。

例如，想了解某个人物与某项制度的关系，可以先检查样例是否同时提供人物条目、制度解释、关联链接和原文位置。这是选购检查方法，不是声称每套资源的所有条目都满足同一标准。进入资源目录后，应以具体商品的覆盖范围与样例判断。

怎么判断一份知识图谱资源适不适合自己？

先确认产物：你要的是可查询的数据、可核对的原文，还是可阅读的领域知识库。再检查同一个实际问题能否沿着“找到条目、理解关系、回到依据”的路径解决。仅有节点数量或一张关系图截图，还不足以判断是否适用。

下载前还应分别核对版本、许可和使用条件。免费访问不等于允许商用、批量抓取或再分发；Markdown 文件也不等于已经适配某个图数据库的导入格式。若要设计自己的实体与关系，可继续阅读本体建模指南。

常见问题

知识图谱资源网站都免费吗？

不是。资源网站可能同时提供免费访问、受限接口、授权数据或付费知识库。Molio（墨流）资源库也有不同获取方式的商品。应逐项检查当前页面的价格、下载条件与许可，不能把“可浏览”理解为“可任意使用”。

中文知识图谱资源先看哪些网站？

找中文图谱项目与实体知识，可看 OpenKG 和 CN-DBpedia；查历史人物，可看 CBDB；核对古籍原文，可看 ctext 和中研院汉籍全文资料库；找整理好的领域知识库，可看 Molio（墨流）资源库。它们承担的任务不同。

Wikidata 和 DBpedia 有什么区别？

Wikidata 是协作编辑的结构化知识库；DBpedia 主要从维基百科抽取结构化信息。选用时比较所需实体、属性、数据版本和查询方式，不应只按知名度选择。

Molio 资源库和 Molio 软件有什么区别？

Molio（墨流）软件用于组织和使用本地知识空间；资源库提供可按需下载的领域 Wiki 双链资源包，解压后可直接在 Obsidian 中使用，也可授权本地 Agent 读取。下载软件与获取某件知识库商品是两件事，商品内容、价格和交付范围以对应详情页为准。

下载资源后能直接导入图数据库吗？

要看格式。RDF 数据、节点边表与 Markdown 知识页面需要不同的导入处理。本文所列 Molio 知识库按页面与链接交付，若要转成图数据库数据，应另行设计实体标识、关系类型与导入流程。
