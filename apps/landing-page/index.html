01
收集 Collect

把碎片信息
有序收集起来

阅读、浏览、灵感——知识的来源无处不在。Molio 帮助你将这些碎片化的信息汇聚到一处，形成统一的知识入口，不再让有价值的内容散落在各个角落。

  • 支持多种格式导入，Markdown / PDF / 网页剪藏
  • 灵活的 Vault 文件树管理，自由组织知识结构
  • 本地存储，数据始终在你手中
02
沉淀 Deposit

让知识在本地
深度沉淀

收集只是开始，真正的价值在于沉淀。Molio 基于类 LLM_Wiki 的自管理知识库，让你的每一次记录都成为可追溯、可检索、可复用的知识资产。

  • SQLite 本地数据库，持久化存储知识节点
  • 文件树视图 + Markdown 渲染，沉浸式阅读体验
  • 全文检索，快速定位所需知识
03
关联 Connect

让知识之间
彼此连接

知识不是孤岛。Molio 自动构建知识节点之间的关联网络，可视化呈现知识图谱。当你查看一个主题时，相关的知识脉络自然浮现，激发新的思考与灵感。

  • 自动识别知识节点间的关联关系
  • 可视化知识图谱，直观呈现知识网络
  • 双向链接，从任意节点发现新关联
04
创作 Create

连接知识网络
涌现创作

当知识被深度连接，创作不再是凭空创造，而是知识的自然流动与涌现。Molio 让你与 AI 的对话建立在已沉淀的知识之上，每一次创作都有据可依、有源可溯。

  • 支持 Claude Code / Codex / Gemini CLI / Qwen Code
  • 自动加载项目上下文（CLAUDE.md + wiki_prompt）
  • 多轮对话 + 工具调用，深度协作
  • 流式输出，实时响应
05
发布 Publish

排版精美，一键分发全网

创作完成后，Molio 帮你完成最后一步——让内容以最专业的姿态呈现。集成 doocs/md 排版引擎，配合 doocs/cose 一键发布到 30+ 内容平台。

左右分栏实时预览 · 主题字体可调
一键发布到 30+ 内容平台
