01 Collect · Process

从散落碎片，
到可调用的知识底座

Chrome 一键剪藏、Obsidian 目录直接打开、本地文档批量导入，碎片先落进库里；Wiki 自动提取实体与概念、构建索引与摘要，知识图谱在它们之间建立关联。数据被加工，才开始成为底座。

  • Chrome Web Clipper 一键剪藏，纯 Markdown 无锁定
  • 兼容 Obsidian Vault，零迁移直接打开
  • Wiki 提取实体与概念、构建索引摘要，知识图谱建立关联
02 Work · Task

AI Agent 进入空间，
基于你的数据工作

Claude Code、Codex 等 Agent 在你的知识空间里做研究、写作、问答与分析——它们看到的不再是一张白纸，而是你的全部积累。图形界面里选 Agent、看流式输出；微信扫码，手机上随时调用你的底座。

  • Claude Code / Codex 等 Agent 的图形化工作台
  • 任务基于你的数据运行：研究、写作、问答、分析
  • 微信扫码连接，手机里跟你的底座对话

Chrome 扩展离线安装说明
  1. 下载扩展的 .zip 压缩包并解压
  2. 打开 Chrome 浏览器，地址栏输入 chrome://extensions 并回车
  3. 开启右上角的「开发者模式」
  4. 点击「加载已解压的扩展程序」，选择刚才解压的文件夹
  5. 扩展图标会出现在 Chrome 工具栏上，安装完成
