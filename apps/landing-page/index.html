01 Collect

Chrome 一键剪藏
碎片落进库里

浏览网页时看到好内容？Chrome 扩展一键剪藏到你的知识库，自动唤起桌面端定位到刚保存的文件。支持公众号文章、PDF、Markdown 等多种格式。

  • Chrome Web Clipper 一键保存到本地知识库
  • 兼容 Obsidian Vault，直接打开已有目录
  • 纯 Markdown 存储，无厂商锁定
02 Understand

让 AI 先读懂
你的积累

Wiki 构建自动扫描全库生成索引与摘要，双向链接和知识图谱把碎片连成脉络。AI 开始工作前，看到的不再是一张白纸，而是你的全部积累。

  • Wiki 一键构建，自动生成索引与知识摘要
  • 双向链接 + 全文检索，知识可检索、可追溯
  • 知识图谱可视化，脉络自然浮现
03 Work

在知识库上
研究 · 分析 · 创作

不用敲命令行。在图形界面里选 Agent、发消息、看流式输出；手机上扫个微信二维码，还能在微信里跟知识库对话。

  • Claude Code / Codex 等 AI runtime 图形化工作台
  • 自动加载知识库上下文，回答有出处
  • 多轮对话 + 工具调用 + 流式输出
  • 微信扫码连上通道，手机里跟库对话
04 Reflow

产出回写入库，
越用越懂你

研究结论、分析报告、创作初稿——所有产出以 Markdown 存回知识库，成为你积累的一部分。下一次 AI 读库时，读到的是更丰富一版的你。

  • 产出纯 Markdown 存回库，成为可复用资产
  • Wiki 索引同步更新，新积累立即能被读到
  • 飞轮闭合：积累 → 理解 → 工作 → 回流
