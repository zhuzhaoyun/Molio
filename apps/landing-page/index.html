01
收集 Collect

Chrome 一键剪藏
碎片信息有序收集

浏览网页时看到好内容？Chrome 扩展一键剪藏到你的知识库，自动唤起桌面端定位到刚保存的文件。支持公众号文章、PDF、Markdown 等多种格式导入。

  • Chrome Web Clipper 一键保存到本地知识库
  • 兼容 Obsidian Vault，直接打开已有目录，零迁移
  • 纯 Markdown 文件存储，无厂商锁定
02
沉淀 Deposit

让知识在本地
深度沉淀

收集只是开始，真正的价值在于沉淀。Molio 提供类似 Obsidian 的本地 Wiki 体验，基于 LLM_Wiki 的自管理知识库，让你的每一次记录都成为可追溯、可检索、可复用的知识资产。

  • 本地 SQLite 数据库，类 Obsidian 的本地知识库存储
  • 文件树视图 + Markdown 渲染，沉浸式 Wiki 阅读体验
  • 全文检索 + 双向链接，快速定位与关联知识节点
03
关联 Connect

让知识之间
彼此连接

知识不是孤岛。Molio 自动构建知识节点之间的双向链接网络，可视化呈现知识图谱。当你查看一个主题时，相关的知识脉络自然浮现，激发新的思考与灵感，就像 Obsidian 的 Graph View 一样直观。

  • 自动识别知识节点间的关联关系
  • 可视化知识图谱，直观呈现知识网络
  • 双向链接，从任意节点发现新关联
04
创作 Create

Claude Code 图形界面
AI 驱动知识创作

不用敲命令行，在 UI 里选 Agent、发消息、看流式输出。支持 Claude Code / Codex / Gemini CLI 一键切换，自动加载项目 CLAUDE.md 上下文，让 AI 基于你已沉淀的知识进行深度创作。

  • Claude Code / Codex / Gemini CLI 图形化工作台
  • 自动加载项目上下文（CLAUDE.md + wiki_prompt）
  • 多轮对话 + 工具调用 + 流式输出
  • 微信扫码连上个人微信，手机里跟知识库对话
05
发布 Publish

内置 doocs/md 排版，一键分发全网

创作完成后，Molio 帮你完成最后一步。集成 doocs/md 排版引擎，微信公众号、知乎等平台格式一键转换；配合 doocs/cose 一键发布到 30+ 内容平台，告别逐平台复制粘贴。

左右分栏实时预览 · 主题字体可调
一键发布到 30+ 内容平台
