Deploy Anywhere · 部署形态

你的环境，我们适配

从信创内网到个人桌面，从 NAS 到 Docker——一条命令，Molio 跑在你已有的基础设施上，不需要你迁就我们。

信创 / 麒麟 / 统信 UOS 国产操作系统原生适配，arm64 / x86 双架构镜像。白名单网络、内网环境零外联。
NAS / 网盘 群晖、威联通、绿联等 NAS 一键 Docker 部署；数据盘即知识库，关机不丢。
Docker 容器 单容器自包含（daemon + web + CLI），amd64 / arm64 双架构，docker-compose 一键起。
内网 / 离线 零外联依赖，断网环境照跑。镜像提前拉入，二进制托管在自有 OSS，不依赖境外源。
Windows / macOS 桌面端 Electron 原生安装包，个人开发者双击即用；内置 daemon + web + Claude Code CLI。
一键安装脚本 curl … | bash 一条命令：自动检测架构、拉镜像、建配置、启动服务，非技术人员也能跑。
