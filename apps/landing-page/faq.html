Molio 是什么？

Molio 墨流是兼容 Obsidian Vault 的本地知识库应用，内置 Claude Code 图形界面、微信 AI 助手和 Chrome Web Clipper。

核心特点：

  • 兼容 Obsidian Vault，直接打开已有知识库
  • Claude Code / Codex / Gemini CLI 图形界面
  • 微信扫码连上个人微信，手机里跟知识库对话
  • Chrome Web Clipper 一键剪藏网页
  • 内置 doocs/md 排版，一键发布到 30+ 平台
  • 数据全在本地，不经过任何第三方服务器

Molio 和 Obsidian 有什么区别？

Molio 完全兼容 Obsidian Vault，可以直接打开你的 Obsidian 文件夹，无需迁移。

主要区别：

  • AI 集成：Molio 内置 Claude Code 图形界面，Obsidian 需要插件
  • 微信助手：Molio 支持微信扫码对话，Obsidian 无此功能
  • Web Clipper：Molio 内置浏览器剪藏，Obsidian 需要插件
  • 多平台发布：Molio 内置 doocs/cose，一键发布 30+ 平台

如果你已经是 Obsidian 用户，Molio 可以作为补充工具，或者直接替代 Obsidian 使用。

Molio 是免费的吗？

Molio 是开源软件，可以免费使用。

你需要自行配置 AI 助手（如 Claude Code）的 API Key，AI 使用的费用取决于你选择的模型提供商：

  • DeepSeek：性价比高，推荐新手
  • OpenRouter：支持多种模型
  • 硅基流动：国内模型提供商
  • Anthropic API：Claude 官方 API

Molio 本身不收取任何费用，你可以从 下载页面 免费获取。

如何安装 Molio？

步骤 1：下载安装包

访问 molio.cn/download.html 下载对应系统的安装包：

  • Windows 用户：下载 .exe 文件
  • macOS 用户：下载 .dmg 文件（Apple Silicon）

步骤 2：安装 AI 助手

安装完成后，还需要安装并配置 AI 助手（如 Claude Code）才能使用 AI 功能。详细步骤请参考 使用指南。

步骤 3：配置 API Key

在 Molio 运行时页面配置模型提供商的 API Key，即可开始使用。

Molio 支持哪些平台？

桌面客户端：

  • Windows（64 位）
  • macOS（Apple Silicon M1/M2/M3）
  • Linux（开发中）

浏览器扩展：

  • Chrome（COSE 多平台发布扩展）
  • Chrome（Molio Connect Web Clipper 扩展）

如果无法访问 Chrome 商店，可从 下载页面 获取离线安装包。

如何使用 Claude Code？

一键安装（推荐）

  1. 打开 Molio，进入「设置」→「运行时」页面
  2. 点击 Claude Code 旁的「一键安装」按钮即可自动完成

配置 API Key

  1. 前往 DeepSeek 平台 购买 API Token
  2. 在 API Keys 页面获取你的 API Key
  3. 回到 Molio 运行时页面，点击 Claude Code 旁的「模型提供商」，粘贴 API Key 后点击「保存」

详细步骤请参考 使用指南。

Web Clipper 怎么用？

安装扩展

从 下载页面 安装 Molio Connect Chrome 扩展（或直接从 Chrome 商店安装）。

剪藏网页

  1. 在浏览网页时（如公众号文章），点击 Chrome 工具栏的 Molio Connect 图标
  2. 扩展会自动识别页面内容，点击「保存」
  3. Molio 桌面端会自动唤起，并定位到刚保存的文件

如何排版微信公众号文章？

进入排版模式

  1. 在 Molio 知识库中打开一个 Markdown 文件
  2. 点击右上角的「排版」按钮
  3. 进入三栏模式：左侧编辑源码、中间实时预览、右侧样式面板

复制到微信

  1. 排版完成后点击「复制」按钮
  2. 内容会以富文本格式写入剪贴板
  3. 直接粘贴到微信公众号编辑器即可保留格式

Molio 的数据安全吗？

完全安全。Molio 是本地应用，所有数据都存储在你自己的电脑上。

  • 不上传到任何第三方服务器
  • 不收集用户数据
  • 不追踪用户行为
  • 开源代码，可审查
